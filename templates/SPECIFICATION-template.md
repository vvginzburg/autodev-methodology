# autodev/SPECIFICATION.md — <Проект>

Постановка задачи для автономной разработки. Единственный источник требований:
нет ответа здесь → исполнитель принимает разумное решение, не останавливаясь,
и называет его в отчёте отдельной графой. В autodev/DECISIONS.md запись
переносит оркестратор при приёмке — исполнитель файлы процесса не трогает
(roles/contracts.md).

Два исключения из правила «решай сам и не останавливайся»:
- **§0** — его четыре пункта закрываются на фазе 1, до начала разработки;
- **продуктовые развилки принципа 14** — границы продукта, безопасность,
  существенные расходы, смысл пользовательского обещания. Такое не решается
  самостоятельно ни днём, ни ночью: задача останавливается, вопрос уходит
  в autodev/ESCALATIONS.md владельцу.
