# DECISIONS.md — самостоятельные решения разработки

Формат: дата, задача, решение, обоснование. Ведёт оркестратор при приёмке
задач (исполнители отдают решения в отчётах). Человек читает после — это
точки, где агент решал сам.

## <дата> · Txx <Название задачи>

1. **<Решение>** — <почему; отвергнутые альтернативы, если были>.
2. Хвост для Tyy/приёмки: <что будущая задача обязана учесть/закрыть —
   с адресатом!>
