# autodev/DECISIONS.md — журнал решений разработки

Формат: дата, задача, решение, обоснование. Ведёт оркестратор при приёмке
задач (исполнители отдают решения в отчётах).

Две породы записей, различать по пометке:
- **без пометки** — решение принял AI сам (техническое, обратимое). Человек
  читает после: это точки, где агент решал за него;
- **«решение владельца»** — ответ на эскалацию принципа 14. Пришёл из
  autodev/ESCALATIONS.md, решал человек. Здесь запись живёт затем, чтобы
  исполнитель ночью нашёл её в одном месте с остальными и не переоткрывал.

   с адресатом!>
