# autodev/ESCALATIONS.md — решения для владельца проекта

Пакет вопросов, которые AI не закрывает сам (принцип 14). Собирается по ходу
разработки, вручается на границе волны. Работа при этом не останавливается:
задача помечается «ждёт решения» и берётся следующая.

**Что сюда попадает:** решения по границе полномочий принципа 14 SKILL.md.
Технические и обратимые продуктовые детали в делегированном объёме идут
в DECISIONS, не в вопросы владельцу.

**Как писать вопрос.** На языке последствий, а не реализации. Владелец
принимает последствие, а не выбирает между названиями библиотек.
