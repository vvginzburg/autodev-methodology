# Перенос Claude 4.1 в Codex

## Статус

4.1-codex.1-rc1 — первый выпуск, допущенный к пилотному применению после
ограниченной приёмки в Codex 6 сентября 2026. Сравнительное преимущество
и устойчивость на приложении средней сложности этим прогоном не установлены.

## Происхождение и границы

Источник: https://github.com/vvginzburg/autodev-methodology,
Claude commit `b3cf94030702587141f0af42d3b5a803681985ad` (4.1).
Отдельная ветка `codex`; исходная ветка и установленный Claude не меняются.
Последняя правка STATUS в базе ещё не имела поведенческого прогона Claude;
обязательная проверка на стороне Codex. Общая история сохраняется через Git.

## Изменения

- Делегированный стек выбирает система. Исключение о трёх технических вопросах
  первого незнакомого стека удалено: исследование/спайк выполняют агенты.
- Принцип 14 учитывает полномочия и цену последствий; обратимая продуктовая
  деталь не требует вопроса. Явно зарезервированный выбор не обходится.
  Полномочия теперь явно фиксируются в SPECIFICATION §0.6 и брифе.
- Настройка Codex: AGENTS вместо CLAUDE, реальные инструменты подагентов,
  без .claude/settings.json, обязательных глобальных установок и настроек.
- Возобновление учитывает согласование, проверку запуска и приёмку;
  наличие PLAN само по себе не запускает разработку.
- Безопасный возврат учитывает исходное состояние задачи, сохраняет чужие
  изменения. STATUS записывается шагом при каждом исходе и завершении.
- Внешние навыки факультативны: рабочие шаги AutoDev исполнимы самостоятельно.
  Оригинал/адаптация и фактическое применение объявляются; общие пакеты
  не устанавливаются скрыто. Это сознательная адаптация, не проверка
  идентичности поведения Superpowers и собственного порядка AutoDev.
- Git локально допустим; push ограничен согласованной публикацией. Ретро
  продукта формирует предложения, а не меняет установленную методику молча.

## Что сохраняется

Проектирование до стройки, независимый аудит полноты и смысла, роли по рискам,
последовательная реализация, свежий независимый ревьюер, фактические проверки,
решения/эскалации в файлах, отдельная приёмка и обратная связь методике.
Сравнительное испытание и адаптация Vmeste V0 — отдельные задачи.

## Проверки

Рабочие правила проверялись на commit `fb147c9`; финальное дополнение адаптера
описывает фиксацию установленного снимка и не меняет цикл исполнения.
Подготовка учебного проекта началась на незакоммиченном rc1, исполнение — после
фиксации. Это приёмка переноса, не замороженный сравнительный эксперимент.

| Проверка | Фактический результат |
|---|---|
| Штатный quick_validate.py, ссылки, git diff --check | пройдены |
| Независимая текстовая сверка | 3 блокирующих противоречия и 3 уточнения исправлены; проверяющий подтвердил закрытие |
| Локальный API Codex skills/list | пользовательский навык autodev-codex обнаружен, enabled=true |
| Учебная CSV-утилита | 23 теста; независимое ревью T1 с 121 комбинацией и T2 с 12 дополнительными сценариями |
| Делегированный выбор | стек и обратимые детали выбраны системой без технических вопросов владельцу |
| Зарезервированное решение | вопрос выявлен при проектировании; независимая работа продолжалась; подготовленный ответ записан и исполнен |
| Восстановление | после контролируемого завершения T1 свежий оркестратор без истории продолжил T2/T3 по файлам, не повторяя разрешение или T1 |
| Возврат изменений | отдельная учебная подготовка после ВОЗВРАТ восстановила файл задачи, сохранив содержимое владельца и staged diff |
| Приёмка результата | независимая проверка итоговых документов и два запуска руководителем; ответ симулятора «принято», не приёмка реальным владельцем |

Документальный возврат T2 потребовал уточнения руководителя: исправлялся только
путь в отчёте, неизменность кода подтверждена хешами; повтор полного тестирования
не запускался. Не выдавать этот частный маршрут за работу без вмешательства.
В следующем улучшении рассмотреть отдельный маршрут замечаний к отчётам,
не откатывающий принятый проверкой код. Сейчас не расширять объём выпуска.

Границы: не испытаны аварийное выключение/обрыв посреди задачи, пересекающиеся
правки владельца и исполнителя, ЖДЁТ исполнителя на фазе 3, реальные данные,
другие платформы, Pro/телефон и непрерывная удалённая работа. В проверке возврата
была ошибка собственного итогового скрипта проверяющего; независимая проверка
руководителя по заранее сохранённым хешам и staged diff прошла. Побайтную
неизменность внутреннего бинарного индекса Git на всём интервале не заявляем.

Сырые журналы и учебные репозитории сохранены в проекте руководителя, не входят
в публичный выпуск. Фактические модели ролей инструментально не подтверждены;
зафиксировано наследование. Время/стоимость и сравнительная ценность не измерены.
