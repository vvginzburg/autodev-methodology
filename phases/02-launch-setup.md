# Фаза 2 — Настройка запуска (обязательная; урок №1 DocVault)

Цель: доказать, что автономный цикл ФИЗИЧЕСКИ работает, до того как человек
уйдёт. На DocVault пропуск этой фазы стоил вечера: незалогиненный CLI сжёг
12 холостых смен, терминал оказался чужд человеку, права всплывали ночью.

## Чек-лист

1. **Среда запуска — родная для человека.** Человек без терминала → разработка
   в Desktop-сессии (оркестратор в основном контексте + сабагенты). Терминальный
   цикл (`claude -p` в цикле со сменами) — только для людей, живущих в терминале,
   и только после проверки `claude` → залогинен.
2. **Права — ДО старта, применяет человек.** Сгенерировать
   `.claude/settings.json` из templates/settings-template.json (сузить под
   проект), отдать человеку на одно подтверждение. Агент не может выдать права
   сам себе — это защита, не баг. Операции, требующие «красных» подтверждений
   (скриншоты экрана, rm по переменной), — не планировать в автономные фазы.
3. **Сон**: caffeinate в bootstrap CLAUDE.md (сабагент запускает фоном).
   Крышку не закрывать — от неё caffeinate не спасает (проверено).
4. **Бюджет**: оценить токены (reference/budget.md), проверить лимиты подписки,
   решить про Usage credits ЗАРАНЕЕ.
5. **СМОК-ТЕСТ ЦИКЛА** — критерий выхода из фазы: пустышечная задача
   («добавь файл SMOKE.md, закоммить») проходит ПОЛНЫЙ конвейер — исполнитель →
   ревьюер → коммит → push — без единого вопроса человеку и без зависаний.
   Красный смок → чинить настройку, не начинать разработку.

## Выход фазы
Зелёный смок-тест цикла. Человек свободен.
