# Типовые ошибки кода

Список кандидатов, с которого начинают поиск причины. Проверить его дешевле,
чем строить гипотезы с нуля.

**Кто читает.** Исполнитель — когда тест красный и причина не очевидна;
ревьюер — при разборе краевых случаев. Указатель идёт в бриф наравне
с [pitfalls.md](pitfalls.md).

**Чем отличается от pitfalls.md.** Там спотыкается окружение — shell, Xcode,
симулятор, права, подписи. Здесь спотыкается логика программы.

**Каталог не заменяет систематическую отладку.** Ни один пункт не подошёл —
дальше по `superpowers:systematic-debugging`; каталог даёт ему первые
кандидатуры, не более.

**Пометка стеком означает: в Swift-проекте этот пункт можно пропустить.**
Она не обещает, что ошибки нет в третьих языках, — только что компилятор Swift
её не допускает.

## Симптом → куда смотреть первым

| Что видно | Куда смотреть |
|---|---|
| «Не является функцией», «неизвестный метод» | Импорты и модули; Типы |
| Иногда работает, иногда нет | Асинхронность: гонка; Состояние: общая мутация |
| Тест падает через раз; поодиночке зелёные, вместе красные | Состояние, общее между тестами; Асинхронность |
| Тест зелёный, а руками не работает | Проверка, которая ничего не проверяет |
| Зависло, не отвечает, таймаут без ошибки | Асинхронность: взаимная блокировка, блокировка пула; внешний вызов без таймаута |
| Локально работает, в сборочной среде падает | Импорты (регистр пути); окружение — см. pitfalls.md |
| Показаны устаревшие данные | Состояние: кэш, два источника правды, обновление без перерисовки |
| Показаны чужие или перепутанные данные | Асинхронность: ответ пришёл на переиспользованный элемент; Состояние: кэш по неверному ключу; Границы и счёт |
| Пропал последний элемент, лишний элемент | Границы и счёт |
| Ошибка разбора, «неожиданный символ», кракозябры | Форма данных; Кодировка |
| Память растёт, приложение тяжелеет | Асинхронность: незакрытые подписки и таймеры; Замыкания |
| Переполнение стека, бесконечный цикл | Границы и счёт: рекурсия без базового случая, счётчик не двигается |
| Интерфейс не обновился | Состояние; изоляция главного актора |
| Числа сходятся «почти» | Типы: точность; Единицы измерения |
| После обновления данные пропали, приложение не открывается | Миграции и старое состояние на диске |
| Падает при запуске без внятного сообщения | Пустое значение: принудительная распаковка; Хранилище: упавшая миграция |
| Первый запуск падает, второй работает | Порядок инициализации; кэш; гонка старта |

## Пустое значение

- **Обращение к пустоте** — свойство берут у `nil`/`null`/`undefined`; проверки
  нет или она стоит после использования.
- **Функция молча вернула пустоту** — забытый `return` или ветка, из которой
  выхода не написали.
- **Разбор ответа не той формы** — распаковка того, что пришло как ошибка,
  а не как данные.
- **Необязательный параметр без значения по умолчанию** — вызывающий его
  не передал, внутри его считают заданным.
- **Swift: принудительная распаковка** `!` там, где значение законно бывает
  пустым; `try!` на операции, падающей при первом нештатном вводе. Частая
  причина падения при запуске — распаковка в инициализации.

## Границы и счёт

- **Смещение на единицу** — путаница включающей и исключающей границы: `<`
  против `<=`, конец среза, диапазон дат. Сама по себе «длина» в условии
  не ошибка: при `i < length` это правильно, при `i <= length` — выход
  за границу.
- **Забор и столбы** — «N элементов требуют N−1 разделителей» посчитано как N.
- **Пустая коллекция** — код ниже написан в расчёте, что элемент хотя бы один.
- **Единицы измерения** — байты против килобайт, секунды против миллисекунд,
  пиксели против точек.
- **Рекурсия без базового случая** — или база недостижима из-за условия,
  которое не сужается. Симптом: переполнение стека.

## Асинхронность и время

- **Гонка** — две операции читают и пишут одно состояние без согласования.
  Симптом: «иногда работает».
- **Взаимная блокировка** — синхронное ожидание на своей же очереди; два
  замка, взятые в разном порядке. Симптом: тишина вместо ошибки.
- **Блокировка пула потоков** — синхронное ожидание внутри асинхронного кода
  (семафор, `sync`): поток кооперативного пула занят и не отдаётся, при
  нескольких таких ожиданиях пул исчерпан и встаёт всё.
- **Потерянное пробуждение** — подписались после того, как событие сработало,
  либо ждут флаг, выставленный до начала ожидания. Не блокировка: ждать нечего,
  и никто ничего не держит. Лечится проверкой состояния до ожидания или
  источником, который помнит последнее значение.
- **Устаревшее замыкание** — обработчик держит значение на момент подписки,
  а не текущее.
- **Порядок инициализации** — событие пришло раньше, чем закончилась настройка.
- **Незакрытая подписка или таймер** — источник продолжает держать получателя,
  и тот не освобождается. Симптом: рост памяти, работа «мёртвого» экрана.
  Это течь; обращение к освобождённой памяти — другой баг, из ручного
  управления памятью и небезопасных ссылок.
- **Забытое `await`** — дальше по коду идёт обещание, а не значение. Молча
  ломается в JavaScript и Python (предупреждение печатается на сборке мусора,
  а если объект сохранён — не печатается вовсе). Swift не соберёт такой код,
  C# предупредит.
- **Swift: реентерабельность актора** — на `await` внутри метода актора
  вклиниваются другие вызовы. Состояние, прочитанное до `await`, после него
  может быть уже другим.
- **Swift: изоляция** — обновление интерфейса не на главном акторе.
  Строгая проверка параллелизма ловит это на сборке; живые баги остаются там,
  где проверку обошли: `@unchecked Sendable`, `nonisolated(unsafe)`, мосты
  в Objective-C и обработчики завершения из C-библиотек.
- **Swift: отмена кооперативна** — задачу не убивают принудительно. Точки
  приостановки, знающие про отмену (`Task.sleep`, сетевые запросы, дочерние
  задачи группы), бросают `CancellationError` сами; своя проверка
  `Task.isCancelled` нужна только в длинных синхронных участках. Частый баг —
  зеркальный: `CancellationError` проглочен общим блоком перехвата и выглядит
  как обычный сбой. `Task` внутри `.task` отменяется вместе с экраном,
  отдельно созданный `Task { }` — нет.

## Состояние

- **Общая мутация** — объект изменили на месте, а на него смотрят и другие.
- **Два источника правды** — одни данные лежат в двух местах и расходятся.
- **Обновление без перерисовки** — значение изменилось, наблюдатель
  не сработал: ссылка та же или объект не помечен наблюдаемым.
- **Кэш пережил источник** — данные обновились, кэш нет; инвалидации нет
  или она по неверному ключу.
- **Недопустимый переход** — состояние сменилось в обход проверки, которой
  не написали.
- **Состояние, общее между тестами** — файл, база, синглтон или переменная
  окружения не сброшены. Симптом: поодиночке тесты зелёные, вместе красные,
  и порядок запуска решает исход.

## Хранилище и миграции

- **Старое состояние на диске** — код обновился, данные на устройстве
  остались прежней формы. Чистой установки недостаточно: обязательно проверить
  установку поверх предыдущей версии.
- **Миграция без отката** — упала на середине и оставила данные между двумя
  формами.
- **Ключ поменял смысл** — то же имя поля означает теперь другое; старые
  записи читаются неверно и молча.
- **Одновременная запись** — два процесса или устройства пишут одно
  хранилище. Исход зависит от хранилища: файл целиком (список настроек, дамп)
  теряет изменения молча, база возвращает ошибку блокировки, облачная
  синхронизация — конфликт. Тишина и ошибка здесь — симптомы одной причины.

## Форма данных и договор с чужой стороной

- **Ответ изменил форму** — сервер обновился, разбор остался прежним.
- **Не тот контейнер** — массив там, где ждали объект; `data` против
  `data.results` против `data[0]`.
- **Отсутствует обязательное поле** — отправили без него, ошибка вернулась
  проверкой на той стороне.
- **Формат даты** — строка ISO против отметки времени против местного формата;
  часовой пояс потерян при разборе.
- **Кодировка** — UTF-8 против однобайтовой, URL-кодирование, HTML-сущности.
- **Число не пережило JSON** — 64-битный идентификатор ушёл целым, вернулся
  округлённым: разбирающая сторона держит числа в double.

## Типы и приведение

- **Числа сравниваются как строки** — «5» больше «10», потому что сравнение
  посимвольное. В JS осторожно: операторы отношения приводят к числу, если
  одна сторона число, а `+` в той же ситуации склеивает.
- **JS: неявное приведение** — нестрогое равенство и «ложные» значения:
  `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. Пустой массив
  и пустой объект **истинны**; при этом `[] == false` — правда, потому что
  нестрогое равенство сводит обе стороны к числу (`false → 0`, `[] → "" → 0`).
  То есть `if ([])` войдёт в ветку, а `[] == false` пройдёт проверку: два
  противоположных ответа про одно значение. В Python и PHP пустая коллекция,
  наоборот, ложна.
- **Точность дробей** — сумма долей не равна ожидаемой: двоичное представление
  не хранит десятичные дроби точно. Деньги — целыми в минимальных единицах
  либо десятичным типом (`Decimal` в Swift и Python); долю от суммы округлять
  по явно записанному правилу.
- **Потеря разрядов у больших целых** — тип `Number` в JavaScript хранит
  целые точно только до 2^53−1; дальше `2**53 + 1` равно `2**53`. Отдельный тип
  `BigInt` точен, но в арифметике с `Number` не смешивается. В Swift и Python
  целые точные, и баг приходит к ним извне — через разбор JSON.
- **Валидный ноль** — значение `0` или пустая строка законны, но проверка
  на «пусто» их отбрасывает.

## Обработка ошибок

- **Проглоченная ошибка** — пустой блок перехвата или запись в журнал без
  обработки.
- **Перехват не того уровня** — поймали базовый тип и скрыли конкретный.
- **Ошибка внутри обработчика** — код очистки падает и маскирует исходную
  причину.
- **Необработанный отказ асинхронной операции** — поведение разное и его надо
  знать: современный Node завершает процесс с ненулевым кодом, браузер и Swift
  `Task { }` продолжают работу, а результата нет.
- **Сообщение без факта** — «что-то пошло не так» вместо кода и параметров;
  причину потом не восстановить.

## Область видимости и замыкания

- **Затенение имени** — внутренняя область объявила то же имя и скрыла внешнее.
- **Потерянный контекст** — обработчик вызван без объекта, к которому
  относится.
- **Захват переменной цикла** — все замыкания смотрят на одну ячейку.
  Привязку на итерацию даёт только `let`, объявленный **в заголовке** цикла;
  `var` и вынесенное наружу объявление дают общую ячейку. В Python то же
  позднее связывание.
- **Swift: цикл удержания** — возникает, когда объект **владеет** тем, что
  держит его обратно сильной ссылкой: сохранённое замыкание, подписка,
  сильное свойство `delegate`. Замыкание, отданное в очередь или в разовый
  обработчик завершения, цикла не создаёт — оно лишь продлевает жизнь объекта
  до срабатывания, и `[weak self]` там не нужен.
- **Swift: `[weak self]` там, где он не нужен** — зеркальный баг. Объект
  освободился, `guard let self else { return }` молча пропустил работу,
  сохранение не произошло и никто не заметил.

## Импорты, модули, сборка

- **Круговая зависимость** — симптом зависит от системы модулей: в CommonJS
  один из модулей получает частично заполненный объект; в ES-модулях чтение
  `let`, `const` или класса до инициализации даёт ошибку обращения, а вот
  объявления функций поднимаются, и цикл может отработать молча.
- **JS: не то имя импорта** — умолчание против именованного экспорта.
- **Регистр в пути** — работает на macOS, падает на Linux и в сборочной среде.
- **Версия зависимости** — установлена не та, что в замке; поведение
  отличается от документации.

## Строки и поиск по образцу

- **Состояние поиска сохранилось** — глобальный флаг регулярного выражения
  между вызовами помнит позицию.
- **Точка не совпадает с переводом строки** без флага `s` (dotAll);
  в Python это `re.DOTALL`, в `NSRegularExpression` —
  `.dotMatchesLineSeparators`. Флаг `m`, который просят по ошибке, меняет
  только смысл `^` и `$`.
- **Незаэкранированный спецсимвол** принят как выражение, а не как символ.
- **Жадность** — «всё подряд» съедает разделители, нужна ленивая форма.
- **Границы символа** — длина в кодовых единицах не равна числу видимых
  символов; эмодзи и составные символы режутся посередине.

## Проверка, которая ничего не проверяет

- **Тест смотрит на заглушку** — подделан ровно тот слой, где живёт ошибка.
- **Утверждение всегда истинно** — сравнение с тем, что сам же и вычислил;
  проверка на «не пусто» вместо проверки значения.
- **Тест не падает при поломке** — быстрая проба: сломать реализацию нарочно
  и убедиться, что тест покраснел. Графа red→green в отчёте это не заменяет:
  она фиксирует, что тест падал до появления реализации, а зубы он мог
  потерять позже — при переписанном утверждении или подменённой фикстуре.
- **Фикстуры не откалиброваны по реальности** — синтетика оптимистичнее
  живого источника. Урок DocVault: данные с камеры оказались в полтора-два
  раза тяжелее синтетических, и это всплыло только на приёмке.

## Платформа

- **Симулятор не равен устройству** — камера, датчики, буфер обмена, фоновые
  режимы ведут себя иначе.
- **Версия интерфейса системы** — там, где компилятор не проверяет
  доступность: веб в старых браузерах, Android. На платформах Apple прямое
  обращение к новому API компилятор не пропустит, зато пропустит непроверенное
  соответствие протоколу и поведенческие отличия обратно развёрнутых
  компонентов.
- **Не та цель сборки** — собран исполняемый модуль вместо приложения:
  на устройство не ставится и в магазин не принимается.
