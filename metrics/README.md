# Метрики применения AutoDev

Один JSON-файл = один завершённый проект. Отправка добровольная (шаг фазы 5
ретро, с согласия человека): Pull Request с файлом `<ваш-ник>-<проект>.json`
по образцу `_template.json`. Никаких названий продуктов и секретов —
только тип проекта, стек и числа. Принятые файлы автоматически появляются
на публичной панели: https://vvginzburg.github.io/autodev-methodology/

Поля: см. _template.json (все обязательные, notes — свободный).
