# AutoDev для Codex

Отдельный выпуск методики автономной разработки: замысел и значимые решения
остаются у владельца, проектирование, реализация, проверки и исправления —
у системы. Качество результата, скорость и внимание владельца — основные цели.

Ветка `codex` развивается отдельно от Claude. База — Claude 4.1 `b3cf940`.
Рабочая версия rc2 добавляет полный комплект исходных навыков и готовится
к обычному испытанию. Первый rc1 прошёл ограниченную проверку без этих
зависимостей. Состояние и доказательства: [CODEX-PORT.md](CODEX-PORT.md).
Вход агента: [SKILL.md](SKILL.md). Подключение: [reference/portability.md](reference/portability.md).

Навык доступен по имени `autodev-codex`. Пример поручения:
«Начинаем проект по AutoDev Codex. Сначала спроектируем и согласуем план».
Для продолжения читать материалы `autodev/` и AGENTS.md своего проекта.
Установка делает методику доступной; не включает её для каждой мелкой задачи.
Полный состав и подготовка на машине исполнения —
[интеграция навыков](reference/skills-integration.md), источники —
[dependencies/lock.json](dependencies/lock.json). Архивы сохраняют лицензии
и все ресурсы авторов; исходники Claude и глобальные плагины не изменяются.

Сохранены фазы проектирования, независимый аудит ТЗ, свежие исполнители,
независимое ревью, проверки по рискам, приёмка и ретро. Для Codex заменены
настройка запуска, восстановление, работа с разрешениями и подключение навыков.
Технический выбор и обратимые детали выполняются в делегированных границах;
зарезервированные решения остаются у владельца.

История и метрики DocVault/DiskTop относятся к Claude, не доказывают скорость
или качество этого выпуска в Codex. Исходную версию можно посмотреть в Git
по commit базы. Общая автоматическая синхронизация двух систем пока не входит
в выпуск: проверенные улучшения передаются между ними отдельно.
