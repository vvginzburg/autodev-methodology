# Работа с исходниками AutoDev Codex

Это репозиторий методики, а не продукт, автоматически запущенный по ней.
При редактировании методики читать SKILL.md и затронутые фазы/контракты.
Не создавать внутри ещё один продуктовый PLAN и не назначать каждому чату
роль оркестратора по наличию этого файла.

Источник Claude и границы переноса — CODEX-PORT.md. Исторические DEFECTS,
OPEN-QUESTIONS, CHANGELOG и метрики не доказывают поведение выпуска Codex.

Для содержательных изменений правил необходим независимый проверяющий:
он читает фактические файлы и проверяет реалистичные сценарии в изолированной
папке, не меняя исходник. Записывать различие между текстовой сверкой,
практическим прогоном, симуляцией ответа владельца и пользовательской приёмкой.

Запрещено публиковать личные данные и локальные отчёты чужих проектов.
Публикация методики — только в согласованную ветку codex, без изменения Claude.
